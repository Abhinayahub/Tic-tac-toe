# Tic-Tac-Toe Game 🎮

A simple, interactive Tic-Tac-Toe game built using Python. This project implements the classic two-player game where players take turns marking spaces on a 3 × 3 board to achieve three marks in a row.

## ✨ Features

- Two-player gameplay
- Interactive 3 × 3 game board
- Turn-based player moves
- Win detection for rows, columns, and diagonals
- Draw detection when all positions are filled
- Input validation to prevent invalid moves

## 🛠️ Technologies Used

- Python
- Basic programming concepts
- Conditional statements
- Loops
- Functions
- Lists and game logic

## 🎯 How to Play

1. Player X starts the game.
2. Players take turns selecting an available position on the board.
3. The first player to get three marks in a row, column, or diagonal wins.
4. If all positions are filled without a winner, the game ends in a draw.

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your computer.

### Installation

Clone the repository:

```bash
git clone https://github.com/Abhinayahub/Tic-tac-toe.git
```

Navigate to the project folder:

```bash
cd Tic-tac-toe
```

Run the Python game file:

```bash
python tic_tac_toe.py
```

**Note:** Replace `tic_tac_toe.py` with the actual Python filename in this repository if it is different.
